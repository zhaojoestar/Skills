# vision - 图片识别（Kimi K2.5）

当前模型（DeepSeek）没有视觉能力。本技能通过调用 Moonshot Kimi K2.5 多模态 API 识别图片，脚本位于 `scripts/vision.py`（Python 标准库，零依赖）。

## 触发判断（重要）

1. **用户明确给了图片来源**（路径/URL/拖入/说"看这张图"）→ 用对应来源
2. **主动场景**（开发调试、UI 问题、验证渲染、问题疑似与屏幕内容相关）→ **优先 `--screenshot` 主动截图**，将截图与日志/代码/上下文结合分析
3. **未指定来源且语义模糊**（如"看一下这个"）→ 询问图片来源

## 使用方式

```powershell
python <skill目录>\scripts\vision.py <图片路径或URL> ["问题"]   # 识别本地文件或 URL
python <skill目录>\scripts\vision.py --clipboard ["问题"]       # 识别剪贴板截图
python <skill目录>\scripts\vision.py --screenshot ["问题"]      # 全屏截图并识别
python <skill目录>\scripts\vision.py --thinking <来源> ["问题"] # 复杂图表/公式等深度推理
```

- 问题省略时使用默认提示词（中文详细描述 + OCR + 界面识别）
- 首次使用前确保已配置 key：`python ...\scripts\vision.py --config "sk-xxx"`；验证：`--check`

## 输出规范

- 将脚本 stdout **原样**呈现给用户（不添油加醋、不改写）
- 退出码非 0 时：呈现错误信息 + 给出下一步建议（缺 key → 提示配置；额度耗尽 → 提示充值）
- **主动场景必须结合分析**：把视觉信息与日志/报错/代码放在一起解读，给出结论与建议，而不是孤立转述"截图里有……"

## 隐私提示

涉及敏感内容（含个人信息/机密的截图）时，可先提示用户确认是否继续识别。
